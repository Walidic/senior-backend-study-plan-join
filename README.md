# Join the senior backend study plan

To request access to the private `Walidic/senior-backend-study-plan` repository,
[open a join request](https://github.com/Walidic/senior-backend-study-plan-join/issues/new?template=join.yml).
You need a GitHub account.

After Walidic approves your request, GitHub emails you an invitation. Accept the
invitation within 7 days.

## How approval works

1. You submit the join request form.
2. A GitHub Actions workflow replies on the issue.
3. Walidic comments `/approve` or `/deny`.
4. On `/approve`, the workflow adds your account as a collaborator and closes the
   issue with a link to accept the invitation.
